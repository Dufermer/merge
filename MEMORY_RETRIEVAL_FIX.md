# Memory Retrieval Fix Report

## Проблема
CEO возвращал "Test content for heartbeat" на запрос "сколько файлов на рабочем столе?".

## Корень
`buildFallbackDecision()` в `hermes-wrapper.js` проверял слово "файл" как триггер для file read detection. В русском языке "файл" — обычное слово, не обязательно команда чтения.

**Было:** `taskLower.includes("файл")` — любое упоминание "файл" → попытка чтения
**Стало:** только если есть глагол действия: "прочитай"/"читай"/"read"/"открой"

## Дополнительные исправления
1. **Memory similarity threshold** поднят с 0.85 до 0.9 — меньше ложных срабатываний
2. **Vector store очищен** — 22 мусорные записи удалены
3. **Error-ответы не кэшируются** (из предыдущего фикса)
